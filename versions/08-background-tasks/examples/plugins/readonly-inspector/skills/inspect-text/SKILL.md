description: Inspect a UTF-8 text file without modifying it by using the example Plugin's MCP tool.
---

Use `mcp__readonly-inspector__local__inspect_text` with an absolute `path`.
Report the returned line count, character count, and preview. This Plugin is
read-only: do not use Coding Kid's write, patch, delete, or execute tools while
following this Skill unless the user separately asks for a modification.
