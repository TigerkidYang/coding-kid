# Project Context

## Current Purpose

This repository is being rebuilt from scratch.

The immediate purpose is to establish a maintainable project memory system so
future AI-agent chats can resume work with enough context from repository files,
instead of depending on prior chat history.

## Product Scope

The final application or library has not been defined yet.

When the project direction is chosen, record:

- What the project does.
- Who it is for.
- The core workflows.
- The non-goals and constraints.
- The current development status.

## Working Preference

The user wants to work in separate chats, each focused on a specific part of the
project. Each chat should be able to reconstruct the important project context by
reading versioned files.

The memory system should stay practical:

- Store stable project knowledge.
- Keep notes short and factual.
- Update memory when decisions or architecture change.
- Avoid duplicating details that are obvious from source code.
